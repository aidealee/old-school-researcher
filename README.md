# Old-School Researcher

中英文学术写作与修改规范。版本 **1.1.2**，修订日期 **2026-11-09**。

围绕作者工作的优势组织论文，去除机械套话、防御表达、限定、否定、让步和免责声明；完整保留原观点、数字、公式、引用、正式命题及复现信息。规则将科学含义转为具体对象、适用域、证据类型和工作状态的正面表述。表达方式改变后，事实范围和确定程度保持原义。

## 两种独立用法

| 形式 | 文件 | 使用方式 |
|---|---|---|
| Skill | [old-school-researcher/SKILL.md](old-school-researcher/SKILL.md) | 将整个 `old-school-researcher` 目录放入客户端实际使用的 Skill 目录，调用 `$old-school-researcher`。 |
| 项目指令 | [paper-project/AGENTS.md](paper-project/AGENTS.md) | 将文件放到论文项目适用目录，由支持 AGENTS.md 的客户端加载；已有项目指令应先整合再使用。 |

展示名称为 **Old-School Researcher**；目录、元数据 `name` 和调用名称统一为 `old-school-researcher`。`agents/openai.yaml` 只提供界面信息与默认提示语，全部写作规则均在 SKILL.md 内。

两份规则正文逐字相同，SKILL.md 额外包含格式元数据。任意一份完整加载即可执行全部规则，另一份文件、说明文档、测试材料、原仓库和 Python 均非执行依赖。普通聊天工具可明确要求完整读取其中一份并作为本次写作指令；作为参考附件上传与指令加载是两种行为。

Skill 示例：

```text
使用 $old-school-researcher 润色下面的英文论文。
正文用英文，修改说明用中文，保留原文观点、数字、公式和引用。
```

AGENTS.md 示例：在放置该文件的论文目录启动任务，再提交“清理这段中文论文，未命中句逐字保留”。仅诊断、清理、润色、重构／压缩、起草按请求分别执行。重构涉及的实质内容继续受保护。

实际自动加载由客户端配置、文件作用域和指令优先级决定。既有 1.1.1 功能验证采用明确加载单份文件的方式；自动发现结果与规则功能结果分开记录。当前 AGENTS.md 为 32722 个 UTF-8 字节。

## 本次裁决与执行方式

当前版执行以下决定：只讲优势、不说输；散文绝对禁用限定、否定、让步；禁止免责声明和追问；直接纠错；允许多样本研究；取消额外的精确计算及形式证明门槛；必要时按歧义和阅读负担拆句。

所有数字和正式命题、作者观点、复现信息继续保留。核对覆盖对象、条件、结论与引用的对应关系。作者或指定期刊的词汇、标点和节奏风格优先；禁词按语境识别具体含义，限定式措辞统一按 R07 改写。现有编辑模式、语言分工、清理范围、新颖性表达及编号规则延续。

R03 的逐字保护覆盖正式命题、公式、引语、代码等内容；R07 针对可改写散文。受保护内容中的逻辑否定与数学条件仍保留原文。具体片段同时满足表达禁令与原义保留遇到障碍时，记录该片段的待处理状态，并完成其余内容。科学确定程度、数值方向和作者判断保持原义。

三份材料 202 项要求、27 项冲突决定及 42 类词表的当前位置与处理见 [完整要求对照](完整要求对照.md)；修订摘要见 [本次变更与对应](本次变更与对应.md)。完整 1–27 编号已从相关历史交接找回，此前关于第 21、22、24–27 项材料缺失的说法已更正。
